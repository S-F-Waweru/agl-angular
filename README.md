# AGL Angular website

Angular conversion of the supplied Alternative Glasses Limited website. The copy, colors, layout, typography, inline logo, SVG illustrations, filtering, lightbox, mobile navigation, animations, and form behavior are preserved.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Production build

```bash
npm run build
```

The production files are written to `dist/agl-angular/browser`.
